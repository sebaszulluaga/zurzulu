Dudas comunes.

Respuestas cortas para que el cliente entienda rápido.

¿Qué necesito para empezar?

Lo básico: nombre del negocio, servicios, WhatsApp, logo si ya existe y cualquier referencia visual que te guste.

¿La página funciona en celular?

Sí. La web está pensada primero para móvil y luego para pantallas más grandes.

¿Incluye dominio y hosting?

Puede incluirse según el plan o manejarse por separado. Se define en la propuesta real del proyecto.

¿Puedo pedir cambios después?

Sí. Hay revisiones incluidas dentro del alcance y cambios adicionales se gestionan aparte si es necesario.
